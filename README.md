# Residencial Los Robles Conectados

Proyecto web desarrollado en React para la gestión de reportes dentro del residencial Los Robles.

## Descripción del proyecto

La plataforma permite registrar reportes relacionados con situaciones del residencial, con el objetivo de mejorar la comunicación entre residentes y administración.

## Revisión de modificaciones
